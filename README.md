# TMDB Movies & TV App

A dynamic web application that interacts with the [TMDB API](https://www.themoviedb.org/) to display popular movies, TV shows, search results, and detailed information. Users can browse popular content, view movie/TV details, and search for their favorite titles. The project demonstrates vanilla JavaScript DOM manipulation, API integration, and responsive UI design. 

This project was built as part of an online JavaScript course

## Features

- Display 20 most popular movies and TV shows  
- View detailed information for movies and TV shows, including genres, ratings, and production companies  
- Search movies and TV shows with live results  
- Pagination for search results  
- Responsive slider showcasing currently playing movies  
- Active link highlighting and alert notifications  

## Technologies Used

- **JavaScript (ES6+)** – Core language
